# 株価四本値(/equities/bars/daily)

`GET`    /v2/equities/bars/daily

## APIの概要

株価データを取得することができます。\
株価は分割・併合等を考慮した調整済み株価と調整前の株価を取得することができます。

> **Warning**
>
> **時価総額（`MktCap`）は本APIから削除予定です。**\
> 今後は[バリュエーション指標API](/ja/spec/eq-valuation)の `MktCap` をご利用ください。同APIの時価総額は自己株式を控除した株式数を用いており、自己株式を含む株式数を用いる本APIの時価総額とは値が一致しない場合があります。\
> 削除の時期は決まり次第、本ページと[リリースノート](/ja/spec/release)でご案内します。

### 本APIの留意点

> **Info**
>
> - **収録データ範囲について：**
>   - 収録対象は東証上場銘柄です。東証上場銘柄でない銘柄（地方取引所単独上場銘柄）およびPTSは収録対象外です。英字を含む銘柄コード（`186A` 等）の銘柄も収録対象です。[FAQ「地方取引所やPTSのデータは取得可能ですか？」](/ja/help/data#data-q2)もあわせてご参照ください。
>   - 上場廃止銘柄についても、データ格納期間内であれば、上場していた期間の日付・期間を指定して取得できます。[FAQ「上場廃止となった銘柄のデータは取得できますか？」](/ja/help/data#data-q16)もあわせてご参照ください。
>   - 四本値（`O`・`H`・`L`・`C`）・取引高（`Vo`）・取引代金（`Va`）は、いずれも東京証券取引所の立会内取引のみを対象としています。ToSTNeT-1、ToSTNeT-2、ToSTNeT-3、立会外分売等の立会外取引は含みません（前場・後場別の項目も同様です）。
> - **欠損値（Null）・レコードの返却について：**
>   - 取引が存在しない日（無約定・終日売買停止等）についても、当該銘柄の上場期間かつデータ格納期間内の営業日であれば、当該銘柄・当該営業日のレコード自体は返却されます。ただし、その場合、四本値、取引高と売買代金は、Nullが収録されています。約定がない場合はNullで表現する仕様のため、取引高（`Vo`）・売買代金（`Va`）に 0 が収録されることはありません。
>   - また、日通しの四本値・取引高（`Vo`）・売買代金（`Va`）は揃ってNullになり、一部の項目だけがNullになることはありません。調整済み項目（`AdjO` 等）がNullになるのも、対応する調整前項目がNullの場合のみです。
>   - 2020/10/1のデータは東京証券取引所の株式売買システムの障害により終日売買停止となったため、四本値、取引高と売買代金はNullが収録されています。
> - 取引が存在しない日を判別するための専用のステータス項目、および取引がなかった理由（無約定か売買停止か等）を区別する情報は提供しておりません。機械的には「四本値・`Vo`・`Va` が揃ってNull」であることをもって「当日約定なし」とご判定ください。売買停止に関する情報の提供状況は[FAQ「売買停止やコーポレートアクションを収録したデータは提供していますか？」](/ja/help/data#data-q22)をご参照ください。
> - 取引代金（`Va`／`MVa`／`AVa`）は価格調整の対象外です（調整前・調整済みで取引代金の値は同一です）。
> - 本APIの価格項目は東京証券取引所における円建て取引に基づく値であり、東証上場の外国株を含め全銘柄、円建てです。
> - 日通しデータについては全プランで取得できますが、前場/後場別のデータについてはPremiumプランのみ取得可能です。
> - Premiumプラン以外のプランでは、前場/後場別のデータ項目はNullで返却されるのではなく、キー自体がレスポンスに含まれません。前場/後場別以外の項目は、値がNullの場合でもキー自体は常にレスポンスに含まれます。
> - 株価調整については株式分割・株式併合・ライツイシューに対応しております。現金配当による調整は含まれず、その他一部コーポレートアクションにも対応しておりませんので、ご了承ください。
> - ライツイシューは、割り当てられた新株予約権がすべて行使されたと想定して調整を行います（実際の行使状況は反映されません）。
> - ライツイシューでは取引高（`Vo`/`AdjVo` 等）は調整されません。
> - 外国株（外株）および TOKYO PRO MARKET 上場銘柄のライツイシューは、株価調整の対象外です（`AdjFactor = 1`）。
> - 調整前の値と調整済みの値（調整係数を含む）は同一レコードで提供しています。調整済みの値は後続のコーポレートアクションに伴って遡及して再計算されるため、各時点で実際に配信されていた値を用いる分析（point-in-time）には、当時値である調整前の値をご利用ください。算出手順は[調整済み株価の計算方法](/ja/spec/eq-bars-daily/adj)をご参照ください。
> - 日通ストップ高フラグ（`UL`）は、終値に基づく判定ではありません。終値がストップ高水準に達していない場合でも、当日の約定値段（高値）が当日の制限値幅上限に到達していれば「1」が収録されます。
> - 特別気配の発生状況・値幅の上限下限を直接示す項目は提供しておりません。

> **Info**
>
> - 各データがJ-Quantsで利用可能となった日時は提供しておりません。更新頻度および更新時刻の目安は[提供データの更新タイミング](/ja/spec/data-update)をご参照ください。
>
> - データ仕様について過去にお問い合わせのあった内容は、[FAQ（データ内容・仕様）](/ja/help/data)にも記載しておりますので、あわせてご参照ください。

### データ訂正のポリシー

> **Info**
>
> - 本サービスにおいて、データ不備・不足によるデータの追加・上書き修正を行う場合がございます。その場合には、[データ修正履歴・制約事項](/ja/spec/fix-data-info)に修正履歴を記載しておりますのでご参照ください。\

## 日次の株価データを取得します

`GET` `https://api.jquants.com/v2/equities/bars/daily`

データの取得では、銘柄コード（code）または日付（date）の指定が必須となります。

### パラメータ及びレスポンス

データの取得では、銘柄コード（code）または日付（date）の指定が必須となります。\
各パラメータの組み合わせとレスポンスの結果については以下のとおりです。

- code: ✓, date: –, from /to: – → 指定された銘柄について全期間分のデータ

- code: ✓, date: ✓, from /to: – → 指定された銘柄について指定された日付のデータ

- code: ✓, date: –, from /to: ✓ → 指定された銘柄について指定された期間分のデータ

- code: –, date: ✓, from /to: – → 全上場銘柄について指定された日付のデータ

### Requests

### Headers

| Parameter | Type   | Required | Description |
| --------- | ------ | -------- | ----------- |
| x-api-key | string | Required | APIキー       |

### Query Parameters

> **Note**
>
> **code** または **date** のいずれか一つの指定が必須です。

| Parameter       | Type   | Required | Description                                                                              |
| --------------- | ------ | -------- | ---------------------------------------------------------------------------------------- |
| code            | string | Optional | 銘柄コード（e.g. 27800 or 2780） 4桁の銘柄コードを指定した場合は、普通株式と優先株式等の両方が上場している銘柄においては普通株式のデータのみが取得されます。 |
| date            | string | Optional | from と to を指定しないとき（e.g. 20210907 or 2021-09-07）                                          |
| from            | string | Optional | fromの指定（e.g. 20210901 or 2021-09-01）                                                     |
| to              | string | Optional | to の指定（e.g. 20210907 or 2021-09-07）                                                      |
| pagination\_key | string | Optional | 検索の先頭を指定する文字列 過去の検索で返却された pagination\_key を設定                                            |

### APIコールサンプルコード

/v2/equities/bars/daily

**cURL**

```bash
curl -G https://api.jquants.com/v2/equities/bars/daily \
-H "x-api-key: {{apiKey}}" \
-d code="{{code}}" \
-d date="{{date}}"
```

**JavaScript**

```javascript
import axios from 'axios'

const client = axios.create({
  baseURL: 'https://api.jquants.com',
  headers: { 'x-api-key': '{{apiKey}}' },
})

await client.get('/v2/equities/bars/daily', {
  params: {
    code: '{{code}}',
    date: '{{date}}',
  },
})
```

**Python**

```python
import requests

headers = {"x-api-key": "{{apiKey}}"}
resp = requests.get(
    "https://api.jquants.com/v2/equities/bars/daily",
    params={"code": "{{code}}", "date": "{{date}}"},
    headers=headers,
)
print(resp.json())
```

| AVa       | number | Required | 後場取引代金（円単位）（※2）                                                                                         |

| MktCap    | number | Required | 時価総額（百万円）（※3）                                                                                           |
| ExRT      | string | Required | 権利落種類（1：株式分割, 2：株式併合, 3：ライツイシュー。株式無償割当は「1：株式分割」に含む）（※4） 調整済み取引高をご自身で再計算する際に、ライツイシューの権利落ち日を判別するために利用します。 |

※1 過去の分割等を考慮した調整済みの項目です\
・調整済みの価格・取引高とも、小数点以下第2位を四捨五入し小数第1位までの値を配信しています。\
・株式分割・株式併合・ライツイシュー等の発生に伴い、過去分の調整済みの値は遡及して再計算されます。調整前の四本値・取引高（`O`・`H`・`L`・`C`・`Vo`、前場・後場の各項目も同様）は事後に変更されません。[FAQ「調整済み株価は過去のデータまでさかのぼって修正されますか？」](/ja/help/data#data-q6)もあわせてご参照ください。\
・各過去時点で配信していた調整済みの値をAPIから取得する方法は提供しておりません。必要な場合は、事後に変更されない調整前の値と `AdjFactor` から算出してください（[調整済み株価の計算方法](/ja/spec/eq-bars-daily/adj)）。\
※2 Premiumプランのみ取得可能な項目です（Premiumプラン以外のプランでは、キー自体がレスポンスに含まれません）\
※3 時価総額 ＝ 終値（調整前）× 上場株式数で算出し、百万円単位（百万円未満を四捨五入）で収録しています。\
・時価総額は、分割・併合等のコーポレートアクションにも対応しております。\
・ETF・ETN等はNullとなります。\
・取引が存在しない日はNullとなります。\
※4 権利落ち日に該当するコーポレートアクションが無い日はNullが収録されます。
