kabu ステーションⓇAPI サービス利用規定 
 
第 1 条（目的） 
この規定は、三菱 UFJ e スマート証券株式会社（以下、「当社」といいます。）の証券口座を持つお客様が、
当社の取引ツールである「kabu ステーションⓇ」を通じて、当社のアプリケーション・プログラミング・インタフェース
サービス（以下、「API」といいます。）を利用するにあたり、その取扱い及び遵守事項等を定めるものです。 
 
第 2 条（API の利用） 
1. お客様は、本利用規定の定めに従い、kabu ステーションⓇを通じて API を利用することができます。 
2. お客様が API を利用するに際しては、当社電子契約画面において、利用許諾の同意および設問の回
答が必要となります。 
3. API を利用する場合は、kabu ステーションⓇ側での設定が必要となります。自らの責任において API サ
ービス内容を検討するお客様は、API を利用するために必要な一切のパスワード等情報を、自己の責任
において、管理及び保管するものとし、これを 第三者に利用させることや、貸与、譲渡、名義変更、売買、
質入等をすることは禁止します。 
4. API を利用した金融商品取引に関する取り決めは、当社が別途定めたオンライン・トレード取扱規定に
よるものとします。 
5. API によりお客様が利用できる金融商品取引・金融商品情報サービスの内容は、当社が別途定めるも
のとします。詳細につきましては、kabu ステーションⓇAPI ポータルサイトにてご確認ください。 
6. お客様は、口座情報ならびに、設定をした API パスワードを自己の責任のもとで管理するものとします。
お客様による口座情報、パスワードの管理失当もしくは使用上の過誤があった場合、または利用者の過
失により第三者 からの不正使用があった場合等により利用者 が被った損害または損失の責任は、利用
者が負うものとし、当社は一切の責任を負わないものとします。 
7. 利用者は、API の利用に関し、コンピューターウィルス への感染防止、第三者による ハッキング、改ざんま
たはその他のネットワーク への不正侵入または 情報漏洩等 を防止するために 必要な安全対策を、 利用
者の費用と責任において講じるものとします。 利用者がかかる安全対策を怠ったことにより 発生した損害
または損失の責任は利用者が負うものとし、当社は一切の責任を負わないものとします。 
 
第 3 条（API 等利用の制限及び遵守事項） 
1. API 及びその一切の派生物に関する著作権及び特許権等の知的所有権並びにその他一切の権利は
当社に帰属します。また、金融商品情報サービス に関しての権利は、当社に帰属します。お 客様はご自
身で利用する以外に金融商品情報サービス の内容を、その目的の如何に関わらず、複製、加工、再利
用又は転載すること、及び API 自体を構成するコード等については、目的の如何に関わらず、複製、加
工、再利用又は転載することは一切できません。また、API 及びその派生物を当社から許諾を受けた
目的外で使用する行為を禁じます。 
2. 当社は、お客様に対し、金融商品情報サービス の内容を第三者へ販売すること、第三者へ再配信する
こと、第三者と共同で利用すること、情報を閲覧している端末機以外へ転載することを禁じます。また、イ
ンターネットアクセスポイントを不明にすること及びお客様の ID、パスワード等を利用して当社のデータベー
スにアクセスして情報を入手する行為その他スクリーンスクレイピング に類する一切の行為であって、当社
がシステムの負荷を増加させると判断する行為を禁じます。 
3. 当社は、「犯罪による収益の移転防止に関する法律」に基づき、特定取引を行う際に取引時確認を行
うほか、特定業務において収受した財産が犯罪による収益である疑いが認められる場合等取引の 正当
性に疑義が生じた場合、その他金融商品取引法等 の法令、又は 日本証券業協会若しくは金融商品
取引所等の 諸規則に違反するおそれがある 取引が存する場合には、 法令又は当社規定に 基づき、遅
滞なく、取引規制その他必要な措置を行います。また、その他金融商品取引法等の法令、又は日本証
券業協会若しくは金融商品取引所等の諸規則に抵触する一切の行為を禁じます。 
4. お客様は、API の複製、逆アセンブル、逆コンパイル又はリバースエンジニアリングを行うことはできません。 
5. お客様は、API の全部又は一部を改変することはできません。 
6. お客様は、API を第三者に対し、有償、無償を問わず、譲渡、使用許諾その他の方法で使用させては
ならず、また、担保の目的に供することはできません。 
7. お客様は、kabu ステーションⓇのアクセスパスワード等を第三者へ開示若しくは漏洩し、又はかかるリスク
を高める行為を禁じます。 
8. 公序良俗に反し、他人に著しい不快感を与え、又は当社の風評リスクを高めるおそれのある行為を禁じ
ます。 
9. Kabu ステーションⓇAPI では、お客様のご利用状況、リクエスト情報を以下目的のため、利用時に保存
されるほか、当社にも自動でアップロード送信させていただきます。 利用状況の収集目的としては、 サービ
スの利用状況の分析、インターフェース の機能拡張計画、システムのリソース拡張計画のため。収集デー
タとしては、API のリクエスト時刻、呼び出しインターフェース、呼び出しに伴うパラメータ等を保存します。 
10. お客様の誤発注を防止するため、kabu ステーションⓇにてお客様が一度に発注できる上限金額を設定
できる機能（ソフトリミット）を提供いたします。当該上限金額を超える注文は発注されません。また、当
社においても、お客様の注文に対しては流量制限(一定時間内の発注件数制限)を設けております。当
該制限を超過する注文は同様に発注されません。 
11. お客様は、当社の同意を得ることなく当社の商標、社名及びロゴマーク等を使用することはできません。ま
た、当社のシステム等に付されている当社の著作権表示及びその 他の権利表示を削除し、又は改変す
ることができません。 
12. お客様は、当社、当社の提携先、その他の第三者の知的所有権を侵害し、これらの者の財産・信用・
名誉等を毀損し、プライバシー権、肖像権その他の権利を侵害することができません。 
13. 当社の運営するサイト、サーバー、当社のシステム等に関し、コンピューターウィルスを感染させ、ハッキング、
改竄、もしくはその他の不正アクセスを行う等、当社のシステム等の安全性を低下させる行為、当社のシ
ステムの負荷を著しく増加させる行為を禁じます。 
14. お客様は、必要な知見なく、API 連携を実施することができません。 
15. お客様は、API 及びその派生物を金融商品仲介業において使用することはできません。 
16. 当API を経由してアクセスする当社のシステムまたは当社のプログラムの全部または一部（その内容に関
する情報を含みます。）を第三者に使用許諾、販売、貸与、譲渡、開示または リースする行為を禁じま
す。 
17. 第三者の作成されたプログラム等を利用することを禁じます。 
18. 商品の区分(現物取引、信用取引) 、執行条件（成行、指値等） の別にかかわらず、 同一銘柄に対
しての注文は 5 件を上限としてご利用ください。 
19. お客様が前各項に違反すると当社が判断した場合、または当社がAPI の運用上必要と判断した場合、
当社は事前の通告なしに API の提供を制限または中止することがあります。 
 
 
第 4 条（免責事項） 
1. API の提供は、技術的に不可避な理由によって情報伝達の遅延や中断が生じる場合があります。 
2. API の内容については万全を期しておりますが、当社はその内容を保証するものではありません。API サ
ービスによって生じたいかなる 損害についても、 当社は、当社に故意または重過失がない限り、その一切
の責任を負いません。また、当社の責に帰すべき場合を除き、API の正確性及び信頼性について責任を
負いません。 
3. 通信機器、通信回線、商用ネットワーク及びコンピューター等の障害によって生じた API の処理及び伝
達遅延、誤謬及び欠陥については、当社に故意または重過失がない限り、その責任を負いません。 
4. お客様が不正利用を行っていると認められた場合及び取引所又は当社システムに過度な負荷を与える
利用等が認められた場合、当社は当社の判断に基づき事前の通告なしに API の提供を中止することが
あります。また、これによって生じたいかなる損害についても当社は一切責任を負いません。ただし、当社に
故意又は重過失が認められる場合には、この限りではありません。 
5. お客様が作成したスクリプト等に関しての誤動作について、当社としては全部免責とさせていただきます。 
6. 第三者が作成したプログラム等の利用は禁止させていただきます。当該プログラム等の利用による資産損
失及びその一切の関連損失はお客様の責任となります。 
7. 同サービスはお客様の端末のパフォーマンスに依存するため、当 API を経由した情報配信、注文要求、
その他照会の要求返信への対応処理時間、正確性に関しては、その責任を負いません。。 
 
第 5 条（その他） 
1. API のサービス内容は、お客様への予告なしに変更・終了される場合があります。 
2. 変更日以降は 変更後の内容に従い取り扱うこととします。かかる 変更内容により万一お 客様に損害が
生じた場合でも、当社に故意又は重過失が認められない限り、当社は責任を負いません。 
3. 本規定に掲載のない事項については、当社のオンライン・トレード規定等の諸規定・約款によるものとしま
す。
